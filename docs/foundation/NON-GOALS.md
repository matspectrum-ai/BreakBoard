# Non-goals — Current Planning Scope

Not current commitments:
- reproducing chess exactly or requiring chess knowledge;
- MMORPG/open-world scope;
- high-volume handcrafted characters, maps, sprites, or 3D assets;
- real-time combat;
- multiplayer in initial implementation scope;
- pay-to-win meta-progression;
- unseeded randomness in gameplay resolution;
- choosing engine/language before requirements justify it;
- production source code during the planning lock.

These are scope controls for the current phase, not permanent prohibitions.
